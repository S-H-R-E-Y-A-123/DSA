# Data Structures and Algorithms in C

A collection of C programs covering fundamental Data Structures and Algorithms, with simple implementations for practice and learning.

## Topics Covered

### Searching
- Linear Search
- Binary Search

### Sorting
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Linked Lists
- Singly Linked List
- Doubly Linked List
- Circular Linked List
- Insertion, deletion, reversal, and sorting
- List concatenation

### Binary Search Trees
- BST insertion
- Inorder, Preorder, and Postorder traversal
- Finding minimum and maximum elements

### Graph Algorithms
- Adjacency Matrix
- Adjacency List
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Dijkstra's Shortest Path
